## 3. 기본 메뉴

### 홈
공지(관리자만 작성) · 이번 주 주보 · 헌금 계좌(누르면 계좌번호 복사) · 최신 글 자동 슬라이드

### 우리소식
- **가족소식** — 성도들이 소식을 나누는 게시판. **우리소식을 열면 여기가 먼저 보입니다**
- **교회일정** — 달력. 생일 자동 표시. 리더·관리자가 일정 추가·삭제
- **주소록** — 이름 검색, 라브리·교회학교별 필터

출석체크는 더 이상 여기에 없습니다. 대시보드 `✅ 출첵` 탭으로 옮겼습니다 ([6장](#6-출석체크)).

### 나눔
- **기도제목** — 아멘, 댓글, 응답 완료, 상단 고정, 비밀글
- **행사사진** — 태그 필터, 좋아요, 다운로드
- **찬양/묵상나눔** — 카드를 누르면 유튜브 재생. **파일 첨부** 가능 (악보 PDF·음원·사진·문서, 최대 3개 / 각 5MB)

글쓰기는 오른쪽 아래 + 버튼. 목록은 20개씩 더보기.

### 신청
- **주일식사** — 앞으로 4주 중 선택. 직전 토요일 14시 마감. **이번주 메뉴**가 함께 보입니다
- **교회행사** — 구글 폼으로 신청. 폼이 없으면 담당자 직접 신청 안내

### 내정보
프로필 수정 · 쿠폰 잔액 · 내 기도제목 · 푸시 알림 스위치 · **글씨 크기(4단계)** · 앱 설치 안내 · 로그아웃

글씨 크기는 작게·보통·크게·아주 크게 중에서 고르고, **그 휴대폰에만** 저장됩니다.
어르신 성도께 안내하기 좋습니다.

## 4. 명단에서 빼는 3가지 방법

가장 헷갈리는 부분입니다. 목적이 다르니 구분해서 쓰세요.

| | 출석 미적용 | 탈퇴 (기본) | 탈퇴 (접근 허용) | 가입 거절 |
|---|:-:|:-:|:-:|:-:|
| 성도 자격 | **O** | X | X | X |
| 출석체크 명단 | X | X | X | X |
| 식수 집계·미응답 알림 | X | X | X | X |
| 주소록 | **O** | X | X | X |
| 생일 달력 | **O** | X | X | X |
| 성도 수 통계 | **O** | X | X | X |
| 식권(쿠폰) | **O** | X | X | X |
| 본인의 식사 신청 | **O** | X | X | X |
| 나눔·우리소식 이용 | **O** | X | **O** | X |
| 공지·나눔 알림 | **O** | X | O | X |
| 과거 기록 보존 | O | O | O | O |
| 본인이 되돌리기 | O | X | X | **O** |

### 4.1 출석 미적용

성도 자격은 그대로 두고 **출석·식수 집계에서만** 빼는 표시입니다.

- **쓰는 경우** — 배우자로만 이름을 올린 분, 장기간 쉬시는 분, 가끔만 나오시는 분
- **설정** — 대시보드 → 성도 → 연필 → 소속 라브리 → `출석 미적용`
- **자녀** — 교회학교 그룹 칸에서 같은 값을 고릅니다
- **부부 중 한 분만** 지정하면 그분만 알림이 멈추고 배우자는 계속 받습니다. 미응답 가정 목록에서는 **가정 전원이 미적용일 때만** 빠집니다
- **되돌리기** — 라브리 1~3을 다시 고르면 끝

### 4.2 탈퇴 처리

기록은 남기고 명단에서만 뺍니다.

- **설정** — 대시보드 → 성도 → 연필 → 맨 아래 `이 성도 탈퇴 처리`
- 오조작을 막으려고 목록이 아닌 편집 창 안에만 버튼을 두었습니다
- 가입한 분과 미가입 명단 모두 같은 방법입니다

체크박스 하나로 두 가지 중 하나를 고릅니다.

| | 체크 안 함 (기본) | `홈페이지 접근 허용` 체크 |
|---|---|---|
| 언제 | 보통의 경우 | 좋게 마무리된 경우 (예: 한국 복귀) |
| 나눔·우리소식 | X | O |
| 신청 메뉴 | X | X (메뉴가 사라짐) |
| 주소록·생일·출석·식수 | X | X |

- **복구** — 대시보드 → 성도 → `탈퇴 처리된 성도` 펼치기 → 복구. 탈퇴 전 등급으로 돌아갑니다
- **본인은 되돌릴 수 없습니다.** 앱에는 교회 사무실로 연락하라는 안내만 뜹니다
- **완전 삭제**는 출석 기록이 하나라도 있으면 막힙니다
- **그 가정의 자녀도 함께 빠집니다** — 부서가 지정돼 있어도 주소록·생일·출석에서 제외됩니다

### 4.3 가입 거절

대시보드 → 승인 → 거절. 계정은 지우지 않고 상태만 바꿉니다.
거절당한 분 화면에 `다시 가입 신청하기` 버튼이 뜨므로 본인이 재신청할 수 있습니다.

### 4.4 자녀: 부서 지정 · 미지정 · 출석 미적용

어른은 **라브리 칸**이, 자녀는 **교회학교 부서 칸**이 명단 포함 여부를 정합니다.
부서는 **관리자만** 지정합니다 (대시보드 → 성도 → 연필 → 자녀 목록).
부모는 내정보에서 자녀의 이름·생일·사진만 넣습니다.

| | 부서 지정 (영아부~중고등부) | 미지정 (빈 값) | 출석 미적용 |
|---|:-:|:-:|:-:|
| 출석체크 명단 | O | X | X |
| 주소록 | O | X | X |
| 생일 달력 | O | X | X |
| 부모의 가족현황 줄 | O | O | O |
| 관리자 성도 편집 창의 자녀 목록 | O | O | O |
| **성도 탭에 미지정 숫자로 표시** | X | **O** | X |
| 부모 화면의 생일 입력 독촉 | O | X | X |

**미지정과 출석 미적용은 화면에 나오는 결과가 같습니다.** 차이는 관리자에게 재촉이 뜨는지 하나입니다.

- **미지정** — 아직 안 정한 상태. 대시보드 성도 탭에 `📋 성도 (n)`으로 계속 뜹니다
- **출석 미적용** — 넣지 않기로 정한 상태. 재촉이 사라집니다

즉 출석 미적용은 **관리자가 확인했다는 표시**입니다. 교회학교에 다니지 않는 자녀
(아직 어린 아기, 이미 성인이 된 자녀 등)에게 지정해 두면 미지정 목록에서 계속 걸리지 않습니다.

자녀 칸의 `출석 미적용`은 어른 라브리 칸의 `출석 미적용`과 **같은 값이고 뜻도 같습니다.**

## 5. 가입 · 승인 · 계정 연결

### 5.1 승인 흐름

로그인 → 추가정보 입력 → **`가입 완료 및 승인 신청` 버튼** → 관리자 승인 → 자동 전환

이 버튼을 눌러야만 관리자에게 알림이 갑니다.

### 5.2 승인 대기는 두 가지입니다

| 상태 | 성도 화면 | 승인 목록에 |
|---|---|:-:|
| 추가정보 미제출 | `가입 신청 이어하기` 버튼 | **X** |
| 추가정보 제출 완료 | `가입 승인 대기 중` | O |

"가입했는데 승인이 안 된다"는 문의는 대부분 첫 번째 경우입니다.
신청 메뉴를 한 번 눌러 보시라고 하면 버튼이 나옵니다.

승인하면 성도 화면은 저절로 바뀝니다. 앱을 껐다 켤 필요 없습니다.

### 5.3 미가입 성도

앱을 안 쓰시는 분을 명단에만 올리는 기능입니다. 대시보드 → 성도 → `미가입 성도`

| | 들어감 |
|---|:-:|
| 출석체크 명단 | O |
| 식수 쿠폰의 가정 이름 | O |
| 주소록 (이름·소속만) | O |
| 주소록 세부정보 | X |
| 생일 달력 | X |

### 5.4 계정 연결

그분이 나중에 가입하면 프로필이 둘이 됩니다. 그대로 두면 출석 명단에 이름이 두 번 뜹니다.
성도 탭의 `가입 계정과 연결하기`로 합치세요. 이름이 같으면 안내가 자동으로 뜹니다.

| 항목 | 남는 값 |
|---|---|
| 이름·연락처·주소·생일·사진 | 가입 계정 (본인 입력값) |
| 직분·라브리·가족 | 명단 (관리자 입력값) |
| 등급 | 승인하며 고른 값 |
| 자녀 | 양쪽을 합침 |
| 출석·식수 기록 | 명단 기록이 그대로 넘어감 |

> 이름이 같아도 다른 분일 수 있습니다. **이메일까지 확인**하세요. 되돌리기 어렵습니다.
> 승인 대기 중인 계정은 목록에 안 나옵니다. 먼저 승인하세요.

## 6. 출석체크

**들어가는 길: 내정보 → 대시보드 → `✅ 출첵` 탭.** 예전에는 우리소식 맨 위 버튼이었습니다.

### 6.1 누가 무엇을 체크하나

| 등급 | 출첵 화면에 보이는 범위 |
|---|---|
| 관리자 | 라브리1~3 · 미정 · **모든** 교회학교 부서 · 방문자 |
| 리더 | 자기 라브리 + **담당으로 지정한 교회학교 부서** · 방문자 |
| 선생님 | **담당으로 지정된 부서만** · 방문자 (미지정이면 전체 부서) |

- 대상 주일은 **가장 최근 지난 주일**입니다 (오늘이 주일이면 오늘)
- 교회학교 부서: 영아부 · 유아·유치부 · 초등부 · 중고등부 (부서가 지정된 자녀만 명단에 뜹니다 → [4.4](#44-자녀-부서-지정--미지정--출석-미적용))
- 담당 부서 지정: 성도 → 연필 → `담당 자녀 그룹` (복수 선택)
- **리더도 담당 부서를 지정하면 그 부서를 함께 체크합니다.** 지정하지 않으면 자기 라브리만 보입니다
- **선생님은 지정된 부서만 보입니다.** 하나도 지정하지 않으면 모든 부서가 보이고,
  미완료 부서가 있을 때마다 전체 요약 알림을 받습니다
- **관리자는 지정과 상관없이** 모든 부서를 체크할 수 있습니다
- 결석 사유: 출근/출장 · 여행 · 아파요 · 가족방문 (선택사항)

### 6.2 빨간 점 = 아직 안 끝났다는 표시

맡은 그룹의 **전원**에게 출석 또는 결석이 저장돼야 완료입니다. 하나라도 비어 있으면
맨 위 헤더와 `출첵` 탭 이름에 **빨간 점**이 붙습니다. 방문자는 완료 조건에서 빠지고,
그 주일 저녁 6시 이후에 가입한 분도 빠집니다.

### 6.3 방문자

| | 기명 방문자 | 익명 카운터 |
|---|---|---|
| 무엇 | 이름을 아는 분 | 총원만 세는 숫자 |
| 입력 | 이름 + 분류 + 특이사항 | 성인·학생 +1 / −1 |
| 쓰임 | 심방·연락으로 이어짐 | 총원 집계만 |

### 6.4 통계 화면

| 카드 | 선생님에게 |
|---|:-:|
| 선택한 주일 출석률 (라브리별 + 합계) | X |
| 출석/결석 명단 (결석 사유 포함) | X |
| 교회학교 출석 | O |
| 방문자 현황 | O |
| 기간 출석률 + CSV 다운로드 | X |
| 기간 방문자 | O |

연속 결석은 성도 탭에서 위로 정렬됩니다. 9주까지는 숫자, 그보다 길면 `장기`.

## 7. 식사 · 쿠폰

### 성도
신청 탭 → 주일식사 → 앞으로 4주 중 선택 → 인원 입력

- 마감: **직전 토요일 14시**
- 신청은 **가정 단위**입니다. 한 분이 하면 가정 전체 신청
- "식사 안 함"도 응답입니다. 미응답과 다릅니다
- 화면 위에 **이번주 메뉴**가 보입니다. 입력은 관리자·리더가 `메뉴 입력` 버튼으로 합니다

### 관리자·리더
대시보드 → 식사

- 4주치 예상 식수, `식수내용 복사`(주방용)
- 미응답 가정 목록 + `안내문 복사`(단톡방 붙여넣기용)
- **대신 입력** — 가정 이름을 누르면 대신 신청·수정. 관리자·리더만

### 쿠폰
대시보드 → 쿠폰 (관리자·쿠폰 관리자)

**가정을 고르고 수량을 입력해** 발급·차감합니다 (예전의 +1 / −1 버튼 방식에서 바뀌었습니다).

- 잘못 눌렀으면 바로 뜨는 **되돌리기**로 한 번에 취소할 수 있습니다 (잠시 뒤 사라집니다)
- 잔액보다 많이 차감하려 하면 막힙니다
- QR·계좌 구매 안내 화면이 있고, 성도는 내정보에서 잔액을 확인합니다

## 8. 주보

대시보드 → 주보 (관리자 전용)

1. 주일 날짜 선택 (**이번 주일 1주** + 지난 주보)
2. `지난 주보 불러오기` — 예배순서·섬김표·헌금계좌는 거의 안 바뀝니다
3. 4쪽 구조대로 입력 (`절 나누기`로 성경 본문 자동 분할)
4. `미리보기`로 넘침 확인
5. `임시저장` 또는 `발행`

**손을 멈추면 자동 저장됩니다.** 화면에 `자동 저장됨`이 표시되니 따로 누르지 않아도 됩니다.

- 대표기도자는 **가입 성도 중에서 고릅니다.** 예배 순서에 자동 반영됩니다
- 지난 주일 + 발행 완료 주보는 **읽기 전용**입니다
- 발행하면 성도 홈에 올라가고 알림이 나갑니다
- 글씨는 지면에 맞게 **자동으로 배율이 조정**됩니다. 미리보기 아래에 걸린 배율이 표시됩니다
- 새로 만들 수 있는 주일은 **이번 주일 하나**뿐입니다 (예전에는 2주)

### 인쇄 설정

A4 가로 2장 → 반으로 접으면 A5 4쪽 (앞면 4·1쪽, 뒷면 2·3쪽)
PDF로 저장하면 파일 이름에 주보 날짜가 붙습니다 (`주보 인쇄 2026-11-01`).

| 항목 | 값 |
|---|---|
| 용지 | A4 |
| 방향 | 가로 |
| 배율 | 100% |
| 여백 | 없음 |
| 배경 그래픽 | 켜기 |
| 양면 | 긴 쪽으로 넘기기 |

## 10. 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 가입했는데 승인 목록에 없음 | `가입 완료 및 승인 신청`을 안 누른 상태. 신청 메뉴를 누르면 이어하기 버튼이 나옴 |
| 승인했는데 화면이 그대로 | 보통은 자동 전환. 안 되면 `승인 상태 새로고침` |
| "성도 명단을 불러오지 못했습니다" | 네트워크 문제. **비어 보여도 실제로 빈 게 아님.** 다시 시도 |
| 같은 사람이 명단에 두 번 | 미가입 명단 + 가입 계정. 성도 탭에서 계정 연결 |
| 가끔 나오시는 분께 매주 식사 알림 | 라브리를 `출석 미적용`으로 변경 |
| 교회를 떠나신 분 처리 | 탈퇴 처리. 좋게 마무리됐으면 `홈페이지 접근 허용` 체크 |
| 자녀가 주소록·출석에 안 보임 | 교회학교 그룹 미지정. 성도 탭 연필에서 지정 |
| 쿠폰 관리자가 명단에 없음 | 정상. 성도를 겸하면 등급을 일반 성도로 변경 |
| 마감 후 식사 추가 | 관리자·리더가 식사 탭에서 대신 입력 |
| 주보 입력칸이 잠김 | 지난 주일 + 발행 완료는 읽기 전용 |
| 인쇄가 잘리거나 배경 없음 | A4·가로·100%·여백 없음·배경 그래픽 켜기 |
| 푸시가 안 옴 | 스위치 → 아이폰이면 홈화면 앱 설치 → 휴대폰 알림 차단 해제 순으로 확인 |
| 출석 리마인더가 엉뚱한 사람에게 | 성도 탭에서 `담당 자녀 그룹` 지정 |

## 11. 인수인계 체크리스트

### 11.1 넘겨받는 분이 먼저 할 일

| 순서 | 할 일 | 어디서 |
|---|---|---|
| 1 | 가입하고 **승인**받기 (일반 성도로) | 본인 휴대폰 |
| 2 | 전임 관리자가 **총괄 관리자(ADMIN)로 등급 변경** | 대시보드 → 성도 → 연필 |
| 3 | 대시보드에 7개 탭이 모두 보이는지 확인 | 내정보 → 대시보드 |
| 4 | `/analytics` 접속 확인 | 주소창 직접 입력 |
| 5 | 주보 인쇄 한 번 해 보기 (프린터·용지 설정 확인) | 주보 탭 → 인쇄 |
| 6 | 휴대폰 푸시 알림 켜기 + 홈화면 앱 설치 | 내정보 |

> **2번을 먼저 하세요.** 전임 관리자가 자기 등급을 먼저 내리거나 탈퇴 처리하면,
> 마지막 총괄 관리자 보호 때문에 막힙니다 ([2.5](#25-등급-지정과-보호)).

### 11.2 전임 관리자가 넘겨야 하는 것

- **총괄 관리자가 몇 명인지** — 성도 탭에서 `ADMIN` 표시를 확인하세요
- **담당자 분담** — 쿠폰 관리자(COUPON), 교회학교 선생님(TEACHER), 라브리 리더(LEADER)가 각각 누구인지
- **주보 담당** — 주보는 총괄 관리자만 쓸 수 있습니다
- **쿠폰 구매 QR·계좌** — 쿠폰 탭의 구매 안내 화면에 들어 있는 정보
- **교회 단톡방 링크** — 홈 화면 버튼과 가입 환영 팝업이 함께 씁니다

### 11.3 주간 운영 루틴

| 언제 | 할 일 |
|---|---|
| 주중 (목~금) | 주보 작성 → `발행` (발행하면 금·토 20시, 일 09시에 알림이 나갑니다) |
| 금 20시 이후 | 식사 미응답 가정 확인 → 필요하면 `안내문 복사`로 단톡방에 올리기 |
| 토 14시 (마감 후) | 대시보드 → 식사 → `식수내용 복사` → 주방에 전달 |
| 주일 | 출첵 — 리더·선생님이 각자 입력. **빨간 점이 사라지면 완료** |
| 주일~월 | 출첵이 안 끝난 라브리의 리더에게 자동 알림이 갑니다 (일 20시 / 월 12시 / 월 20시) |
| 수시 | 가입 승인 (알림이 옵니다) · 쿠폰 발급 · 미지정 자녀 부서 정하기 |

### 11.4 알아두면 사고를 막는 것

| 주의 | 이유 |
|---|---|
| 쿠폰 관리자(COUPON)를 성도에게 주지 않기 | 주소록·생일·출석·식수에서 전부 빠집니다 ([2.1](#21-등급-8종)) |
| 계정 연결 전에 **이메일 확인** | 동명이인을 합치면 되돌리기 어렵습니다 ([5.4](#54-계정-연결)) |
| 탈퇴 처리는 편집 창 안에서만 | 기록은 남지만 그 가정의 자녀까지 명단에서 빠집니다 ([4.2](#42-탈퇴-처리)) |
| 알림 직접 보내기는 취소 불가 | 보내기 전 확인 창을 꼭 읽으세요 ([9.2](#92-관리자가-직접-보내기)) |
| 마지막 총괄 관리자는 등급 변경·탈퇴·삭제 불가 | 아무도 관리할 수 없게 되는 것을 막는 장치입니다 |

### 11.5 서버 쪽에서 막고 있는 것 (참고)

화면에서만 막는 게 아니라 서버(Supabase RLS)에서도 확인합니다. 화면을 고쳐도 뚫리지 않습니다.

- **승인 전·거절·탈퇴 계정**은 성도 명단·나눔 글·식사 신청을 읽을 수 없습니다
  (공지는 비로그인 홈 화면에 필요해서 누구나 볼 수 있습니다)
- 사진·첨부 **업로드는 승인된 성도만**
- 글·댓글은 **본인 이름으로만** 저장됩니다
- `커뮤니티 접근 유지`와 `탈퇴 전 등급`은 **본인이 바꿀 수 없습니다** (관리자 전용 값)
