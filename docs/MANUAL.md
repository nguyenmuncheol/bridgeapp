## 3. 기본 메뉴

### 홈
공지(관리자만 작성) · 이번 주 주보 · 헌금 계좌(누르면 계좌번호 복사) · 최신 글 자동 슬라이드

### 우리소식
- **교회일정** — 달력. 생일 자동 표시. 리더·관리자가 일정 추가·삭제
- **가족소식** — 성도들이 소식을 나누는 게시판
- **주소록** — 이름 검색, 라브리·교회학교별 필터
- **출석체크 버튼** — 오른쪽 위. 리더·선생님·관리자만 보임

### 나눔
- **기도제목** — 아멘, 댓글, 응답 완료, 상단 고정, 비밀글
- **행사사진** — 태그 필터, 좋아요, 다운로드
- **찬양/묵상나눔** — 카드를 누르면 유튜브 재생

글쓰기는 오른쪽 아래 + 버튼. 목록은 20개씩 더보기.

### 신청
- **주일식사** — 앞으로 4주 중 선택. 직전 토요일 14시 마감
- **교회행사** — 구글 폼으로 신청. 폼이 없으면 담당자 직접 신청 안내

### 내정보
프로필 수정 · 쿠폰 잔액 · 내 기도제목 · 푸시 알림 스위치 · 앱 설치 안내 · 로그아웃

## 4. 명단에서 빼는 3가지 방법

가장 헷갈리는 부분입니다. 목적이 다르니 구분해서 쓰세요.

| | 출석 미적용 | 탈퇴 (기본) | 탈퇴 (접근 허용) | 가입 거절 |
|---|:-:|:-:|:-:|:-:|
| 성도 자격 | **O** | X | X | X |
| 출석체크 명단 | X | X | X | X |
| 식수 집계·미응답 알림 | X | X | X | X |
| 주소록 | **O** | X | X | X |
| 생일 달력 | **O** | X | X | X |
| 성도 수 통계 | **O** | X | X | X |
| 식권(쿠폰) | **O** | X | X | X |
| 본인의 식사 신청 | **O** | X | X | X |
| 나눔·우리소식 이용 | **O** | X | **O** | X |
| 공지·나눔 알림 | **O** | X | O | X |
| 과거 기록 보존 | O | O | O | O |
| 본인이 되돌리기 | O | X | X | **O** |

### 4.1 출석 미적용

성도 자격은 그대로 두고 **출석·식수 집계에서만** 빼는 표시입니다.

- **쓰는 경우** — 배우자로만 이름을 올린 분, 장기간 쉬시는 분, 가끔만 나오시는 분
- **설정** — 대시보드 → 성도 → 연필 → 소속 라브리 → `출석 미적용`
- **자녀** — 교회학교 그룹 칸에서 같은 값을 고릅니다
- **부부 중 한 분만** 지정하면 그분만 알림이 멈추고 배우자는 계속 받습니다. 미응답 가정 목록에서는 **가정 전원이 미적용일 때만** 빠집니다
- **되돌리기** — 라브리 1~3을 다시 고르면 끝

### 4.2 탈퇴 처리

기록은 남기고 명단에서만 뺍니다.

- **설정** — 대시보드 → 성도 → 연필 → 맨 아래 `이 성도 탈퇴 처리`
- 오조작을 막으려고 목록이 아닌 편집 창 안에만 버튼을 두었습니다
- 가입한 분과 미가입 명단 모두 같은 방법입니다

체크박스 하나로 두 가지 중 하나를 고릅니다.

| | 체크 안 함 (기본) | `홈페이지 접근 허용` 체크 |
|---|---|---|
| 언제 | 보통의 경우 | 좋게 마무리된 경우 (예: 한국 복귀) |
| 나눔·우리소식 | X | O |
| 신청 메뉴 | X | X (메뉴가 사라짐) |
| 주소록·생일·출석·식수 | X | X |

- **복구** — 대시보드 → 성도 → `탈퇴 처리된 성도` 펼치기 → 복구. 탈퇴 전 등급으로 돌아갑니다
- **본인은 되돌릴 수 없습니다.** 앱에는 교회 사무실로 연락하라는 안내만 뜹니다
- **완전 삭제**는 출석 기록이 하나라도 있으면 막힙니다

### 4.3 가입 거절

대시보드 → 승인 → 거절. 계정은 지우지 않고 상태만 바꿉니다.
거절당한 분 화면에 `다시 가입 신청하기` 버튼이 뜨므로 본인이 재신청할 수 있습니다.

## 5. 가입 · 승인 · 계정 연결

### 5.1 승인 흐름

로그인 → 추가정보 입력 → **`가입 완료 및 승인 신청` 버튼** → 관리자 승인 → 자동 전환

이 버튼을 눌러야만 관리자에게 알림이 갑니다.

### 5.2 승인 대기는 두 가지입니다

| 상태 | 성도 화면 | 승인 목록에 |
|---|---|:-:|
| 추가정보 미제출 | `가입 신청 이어하기` 버튼 | **X** |
| 추가정보 제출 완료 | `가입 승인 대기 중` | O |

"가입했는데 승인이 안 된다"는 문의는 대부분 첫 번째 경우입니다.
신청 메뉴를 한 번 눌러 보시라고 하면 버튼이 나옵니다.

승인하면 성도 화면은 저절로 바뀝니다. 앱을 껐다 켤 필요 없습니다.

### 5.3 미가입 성도

앱을 안 쓰시는 분을 명단에만 올리는 기능입니다. 대시보드 → 성도 → `미가입 성도`

| | 들어감 |
|---|:-:|
| 출석체크 명단 | O |
| 식수 쿠폰의 가정 이름 | O |
| 주소록 (이름·소속만) | O |
| 주소록 세부정보 | X |
| 생일 달력 | X |

### 5.4 계정 연결

그분이 나중에 가입하면 프로필이 둘이 됩니다. 그대로 두면 출석 명단에 이름이 두 번 뜹니다.
성도 탭의 `가입 계정과 연결하기`로 합치세요. 이름이 같으면 안내가 자동으로 뜹니다.

| 항목 | 남는 값 |
|---|---|
| 이름·연락처·주소·생일·사진 | 가입 계정 (본인 입력값) |
| 직분·라브리·가족 | 명단 (관리자 입력값) |
| 등급 | 승인하며 고른 값 |
| 자녀 | 양쪽을 합침 |
| 출석·식수 기록 | 명단 기록이 그대로 넘어감 |

> 이름이 같아도 다른 분일 수 있습니다. **이메일까지 확인**하세요. 되돌리기 어렵습니다.
> 승인 대기 중인 계정은 목록에 안 나옵니다. 먼저 승인하세요.

## 6. 출석체크

### 6.1 누가 무엇을 체크하나

| 등급 | 출석체크 화면에 보이는 범위 |
|---|---|
| 관리자 | 라브리1~3 · 미정 · **모든** 교회학교 부서 · 방문자 |
| 리더 | 자기 라브리 하나 · 방문자 (교회학교 부서는 **안 보임**) |
| 선생님 | **담당으로 지정된 부서만** · 방문자 (미지정이면 전체 부서) |

- 대상 주일은 **가장 최근 지난 주일**로 자동 계산됩니다
- 교회학교 부서: 영아부 · 유아·유치부 · 초등부 · 중고등부
- 담당 부서 지정: 성도 → 연필 → `담당 자녀 그룹` (복수 선택)
- **선생님은 지정된 부서만 보입니다.** 하나도 지정하지 않으면 모든 부서가 보이고,
  미완료 부서가 있을 때마다 전체 요약 알림을 받습니다
- **관리자·리더의 부서 지정은 알림 대상만 정합니다.** 관리자는 지정과 상관없이 모든 부서를
  체크할 수 있고, 리더는 부서를 지정해도 출석체크 화면에는 교회학교가 나오지 않습니다
  (통계는 볼 수 있습니다)
- 결석 사유: 출근/출장 · 여행 · 아파요 · 가족방문 (선택사항)

### 6.2 방문자

| | 기명 방문자 | 익명 카운터 |
|---|---|---|
| 무엇 | 이름을 아는 분 | 총원만 세는 숫자 |
| 입력 | 이름 + 분류 + 특이사항 | 성인·학생 +1 / −1 |
| 쓰임 | 심방·연락으로 이어짐 | 총원 집계만 |

### 6.3 통계 화면

| 카드 | 선생님에게 |
|---|:-:|
| 선택한 주일 출석률 (라브리별 + 합계) | X |
| 출석/결석 명단 (결석 사유 포함) | X |
| 교회학교 출석 | O |
| 방문자 현황 | O |
| 기간 출석률 + CSV 다운로드 | X |
| 기간 방문자 | O |

연속 결석은 성도 탭에서 위로 정렬됩니다. 9주까지는 숫자, 그보다 길면 `장기`.

## 7. 식사 · 쿠폰

### 성도
신청 탭 → 주일식사 → 앞으로 4주 중 선택 → 인원 입력

- 마감: **직전 토요일 14시**
- 신청은 **가정 단위**입니다. 한 분이 하면 가정 전체 신청
- "식사 안 함"도 응답입니다. 미응답과 다릅니다

### 관리자·리더
대시보드 → 식사

- 4주치 예상 식수, `식수내용 복사`(주방용)
- 미응답 가정 목록 + `안내문 복사`(단톡방 붙여넣기용)
- **대신 입력** — 가정 이름을 누르면 대신 신청·수정. 관리자·리더만

### 쿠폰
대시보드 → 쿠폰 (관리자·쿠폰 관리자)

발급 +1 / 차감 −1 / 10장 일괄 발급 · QR·계좌 구매 안내 · 성도는 내정보에서 잔액 확인

## 8. 주보

대시보드 → 주보 (관리자 전용)

1. 주일 날짜 선택 (앞으로 2주 + 지난 주보)
2. `지난 주보 불러오기` — 예배순서·섬김표·헌금계좌는 거의 안 바뀝니다
3. 4쪽 구조대로 입력 (`절 나누기`로 성경 본문 자동 분할)
4. `미리보기`로 넘침 확인
5. `임시저장` 또는 `발행`

- 대표기도자는 **가입 성도 중에서 고릅니다.** 예배 순서에 자동 반영됩니다
- 지난 주일 + 발행 완료 주보는 **읽기 전용**입니다
- 발행하면 성도 홈에 올라가고 알림이 나갑니다

### 인쇄 설정

A4 가로 2장 → 반으로 접으면 A5 4쪽 (앞면 4·1쪽, 뒷면 2·3쪽)

| 항목 | 값 |
|---|---|
| 용지 | A4 |
| 방향 | 가로 |
| 배율 | 100% |
| 여백 | 없음 |
| 배경 그래픽 | 켜기 |
| 양면 | 긴 쪽으로 넘기기 |

## 9. 자동 알림 · 푸시

### 9.1 서버가 자동으로 보내는 알림

| 알림 | 시각 | 푸시 | 받는 사람 |
|---|---|:-:|---|
| 식사 미응답 | 금 20시 / 토 12시 | O | 아직 신청 안 한 가정 |
| 새 주보 | 금·토 20시 | O | 전 성도 (주보당 1회) |
| 생일 축하 | 매일 08시 | O | 생일자 + 우리소식 축하글 |
| 출석 리마인더 | 일 20시 / 월 12시 / 월 20시 | O | 출석 미입력 라브리의 리더 |
| 안 읽은 알림 요약 | 11시 / 21시 | O | 안 읽은 알림이 있는 성도 |

대시보드 → 알림 탭에서 보기 전용으로 확인할 수 있습니다.

### 9.2 관리자가 직접 보내기

대시보드 → 알림 → 제목·내용 → 받는 사람 선택

- 빠른 선택: 전체 / 라브리별 / 리더 / 선생님 / 관리자
- 그룹이 겹쳐도 **한 사람이 한 번만** 받습니다
- 보내는 이를 `더브릿지 교회` 명의로 할 수 있습니다
- **되돌릴 수 없습니다.** 확인 창이 한 번 뜹니다

### 9.3 성도 푸시 설정

내정보 → 휴대폰 알림 스위치

| 조건 | 푸시 |
|---|:-:|
| 스위치 켜고 권한 허용 | O |
| 권한을 한 번 차단함 | X (휴대폰 설정에서 풀어야 함) |
| 아이폰 + Safari로 그냥 열기 | X |
| 아이폰 + 홈화면에 앱 추가 | O |

앱 설치: 아이폰은 Safari 공유 → 홈 화면에 추가, 안드로이드는 내정보의 설치 버튼

### 9.4 분석 페이지

주소창에 `/analytics` (관리자만). 메뉴에 없고 검색에도 안 나옵니다.

접속 현황 · 시간대별 피크 · 출석·식사 추이 · 기기 점유율 · 가족별 보기 · 미가입 성도 명단
**목회 돌봄 관심 성도** — 앱에는 들어오는데 2주 이상 결석 중인 분

## 10. 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 가입했는데 승인 목록에 없음 | `가입 완료 및 승인 신청`을 안 누른 상태. 신청 메뉴를 누르면 이어하기 버튼이 나옴 |
| 승인했는데 화면이 그대로 | 보통은 자동 전환. 안 되면 `승인 상태 새로고침` |
| "성도 명단을 불러오지 못했습니다" | 네트워크 문제. **비어 보여도 실제로 빈 게 아님.** 다시 시도 |
| 같은 사람이 명단에 두 번 | 미가입 명단 + 가입 계정. 성도 탭에서 계정 연결 |
| 가끔 나오시는 분께 매주 식사 알림 | 라브리를 `출석 미적용`으로 변경 |
| 교회를 떠나신 분 처리 | 탈퇴 처리. 좋게 마무리됐으면 `홈페이지 접근 허용` 체크 |
| 자녀가 주소록·출석에 안 보임 | 교회학교 그룹 미지정. 성도 탭 연필에서 지정 |
| 쿠폰 관리자가 명단에 없음 | 정상. 성도를 겸하면 등급을 일반 성도로 변경 |
| 마감 후 식사 추가 | 관리자·리더가 식사 탭에서 대신 입력 |
| 주보 입력칸이 잠김 | 지난 주일 + 발행 완료는 읽기 전용 |
| 인쇄가 잘리거나 배경 없음 | A4·가로·100%·여백 없음·배경 그래픽 켜기 |
| 푸시가 안 옴 | 스위치 → 아이폰이면 홈화면 앱 설치 → 휴대폰 알림 차단 해제 순으로 확인 |
| 출석 리마인더가 엉뚱한 사람에게 | 성도 탭에서 `담당 자녀 그룹` 지정 |
