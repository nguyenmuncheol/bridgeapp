## 1. 앱 전체 지도

### 성도가 보는 화면 — 화면 아래 5개 메뉴

| 메뉴 | 서브탭 | 한 줄 설명 |
|---|---|---|
| 🏠 **홈** | — | 교회 소개, 공지사항, 이번 주 주보, 헌금 계좌 |
| 📰 **우리소식** | 교회일정 · 가족소식 · 주소록 | 달력, 성도 소식 나눔, 연락처 명단 (+ 출석체크 버튼) |
| ❤️ **나눔** | 기도제목 · 행사사진 · 찬양/묵상나눔 | 게시판 3종 |
| 📋 **신청** | 주일식사 · 교회행사 | 주일 식사 신청, 행사 신청(구글 폼) |
| 👤 **내정보** | — | 프로필 수정, 쿠폰 잔액, 푸시 알림 설정, 앱 설치 안내, 관리 대시보드 입구 |

### 운영자만 보는 화면

| 화면 | 들어가는 길 | 볼 수 있는 사람 |
|---|---|---|
| 🛠️ **관리 대시보드** | [내정보] → 상단 대시보드 카드 | 총괄 관리자 · 리더 · 선생님 · 쿠폰 관리자 |
| 📊 **분석 페이지** | 주소창에 `/analytics` 직접 입력 | 총괄 관리자만 |
| 🖨️ **주보 인쇄** | 주보 탭의 인쇄 버튼 또는 `/bulletin/print?date=YYYY-MM-DD` | 총괄 관리자만 |

> 💡 **주소 기억**: 각 탭은 주소 끝에 `#news`, `#sharing` 처럼 표시가 붙습니다.
> 그래서 새로고침해도 보던 탭이 그대로 유지되고, 휴대폰 뒤로가기는 "이전 탭"으로 돌아갑니다.

## 2. 권한(등급) 체계

### 2.1 등급 8가지

성도 한 명은 **항상 아래 8가지 중 하나의 상태**입니다.

| 등급 (코드) | 화면 표기 | 어떤 사람인가 |
|---|---|---|
| `ADMIN` | 총괄 관리자 | 목사님 등. 모든 기능을 씁니다. |
| `LEADER` | 라브리 리더 | 자기 라브리 출석을 입력하고, 식사 집계·출석 통계를 봅니다. |
| `TEACHER` | 교회학교 선생님 | **자녀(교회학교) 출석만** 담당합니다. 성도 자격은 일반 성도와 똑같습니다. |
| `COUPON` | 쿠폰 관리자 | **식사 쿠폰 전용 업무 계정**입니다. 성도 명단·집계에는 들어가지 않습니다. |
| `MEMBER` | 일반 성도 | 승인이 끝난 보통 성도입니다. |
| `PENDING` | 승인 대기 | 로그인은 했지만 아직 승인 전입니다. (아래 5장에서 2단계로 나뉩니다) |
| `REJECTED` | 가입 거절 | 관리자가 가입을 거절했습니다. **본인이 다시 신청할 수 있습니다.** |
| `LEFT` | 탈퇴 처리 | 관리자가 탈퇴 처리했습니다. **본인은 되돌릴 수 없고 관리자만 복구합니다.** |

> ⚠️ **쿠폰 관리자(`COUPON`)를 성도에게 주지 마세요.**
> 이 등급은 주소록·생일 달력·출석체크·식수 집계·성도 수 통계에서 **전부 빠집니다.**
> 식권만 담당하는 별도 업무 계정에만 쓰십시오.

| 일반 성도 (`MEMBER`) | ✅ | ✅ | ✅ | ✅ | ✅ | ✗ |

> 🔒 로그인 안내 · ⏳ 승인 대기 안내 · 📬 다시 신청 안내 · 🚪 탈퇴 안내 화면이 대신 뜹니다.
> **홈 탭은 누구에게나 열려 있습니다.** 다만 비로그인·대기·거절·탈퇴 상태에서는
> 최신 글·헌금 계좌 같은 성도 전용 영역이 홈에서도 가려집니다.

### 2.4 관리 대시보드 탭 권한표

대시보드에 들어가면 **자기 권한에 맞는 탭만** 보입니다.

| 탭 | 총괄 관리자 | 리더 | 선생님 | 쿠폰 관리자 |
|---|:---:|:---:|:---:|:---:|
| 🍱 **식사** (식수 집계) | ✅ | ✅ | ✅ | ✗ |
| 👥 **승인** (가입 승인·거절) | ✅ | ✗ | ✗ | ✗ |
| 📋 **성도** (성도 관리) | ✅ | 🔍 읽기 전용 | ✗ | ✗ |
| 🎟️ **쿠폰** (식권 발급·차감) | ✅ | ✗ | ✗ | ✅ |
| 📊 **출석** (출석 통계) | ✅ | ✅ | 🧒 자녀·방문자만 | ✗ |
| 📖 **주보** (주보 작성) | ✅ | ✗ | ✗ | ✗ |
| 🔔 **알림** (알림 발송·점검) | ✅ | ✗ | ✗ | ✗ |

**처음 열리는 탭**: 쿠폰 관리자 → 쿠폰 / 선생님 → 출석 / 그 외 → 식사

**세부 차이**

- **리더의 [성도] 탭**은 명단을 **보기만** 합니다. 성도 정보 수정 ✏️, 미가입 성도 추가,
  계정 연결, 탈퇴 처리, 탈퇴자 목록은 **보이지 않습니다.**
- **성도 명단 CSV 다운로드**는 개인정보라 **총괄 관리자만** 보입니다.
- **선생님의 [출석] 탭**은 `🧒 교회학교 출석`과 `🏷️ 방문자 현황`만 보입니다.
  성인 출석률·성인 출석 명단·기간 합산 결과는 가려집니다.
- **선생님의 [식사] 탭**은 집계를 볼 수 있지만 **대신 신청 입력은 못 합니다.**
  (대신 입력은 총괄 관리자·리더만)

### 2.5 등급을 정하는 곳

| 시점 | 위치 |
|---|---|
| **가입을 승인할 때** | 관리 대시보드 → 👥 승인 → 라브리 · 등급 · 직분 · 가족 지정 후 [승인] |
| **나중에 바꿀 때** | 관리 대시보드 → 📋 성도 → 성도 옆 ✏️ → 등급 변경 |

직분(성도/형제/자매/학생/청년/집사/안수집사/권사/장로/선생/목사/전도사/사모)은
등급과 **별개**입니다. 직분은 이름 뒤에 붙는 호칭이고, 등급은 기능 권한입니다.

### 2.6 마지막 총괄 관리자 보호

아무도 관리 기능을 못 쓰게 되는 사고를 막기 위해, 아래는 **자동으로 차단**됩니다.

- 마지막 남은 총괄 관리자의 **등급 낮추기**
- 마지막 남은 총괄 관리자를 **탈퇴 처리**
- 탈퇴자 중 **마지막 총괄 관리자였던 분의 완전 삭제** (복구용으로 남겨둡니다)

➡️ 먼저 다른 분을 총괄 관리자로 지정한 뒤에 진행하세요.

## 3. 기본 메뉴 간단 설명

### 🏠 홈

- **교회 소개** — 로그인 성도에게는 교회 안내 모달 + 카카오 단톡방 버튼,
  비로그인 방문자에게는 소개·주소·지도 카드가 보입니다.
- **최신 글 띠** — 최근 올라온 글이 2칸씩 자동으로 흘러갑니다. (로그인 성도 전용)
- **공지사항** — 세로로 자동 스크롤됩니다. 작성·수정·삭제는 총괄 관리자만.
- **이번 주 주보** — 주보 사진을 넘겨 보거나 전체보기로 확대합니다.
- **헌금 계좌** — 누르면 계좌번호 숫자만 복사됩니다. (로그인 성도 전용)

### 📰 우리소식

- **📅 교회일정** — 달력입니다. 성도 생일이 자동으로 표시되고, 이달의 생일자 명단이 나옵니다.
  리더·관리자는 날짜를 눌러 일정을 추가·삭제합니다.
- **📣 가족소식** — 성도들이 서로의 소식을 나누는 게시판입니다.
- **📖 주소록** — 이름으로 통합 검색하고, 라브리별/교회학교별로 걸러 봅니다.
- **출석체크 버튼** — 화면 오른쪽 위. 리더·선생님·관리자에게만 보입니다. ([7장](#7-출석체크-운영))

### ❤️ 나눔

- **🙏 기도제목** — 아멘(좋아요), 댓글, 응답 완료 처리, 상단 고정, **비밀글**(작성자·목회자·리더만 열람)
- **📸 행사사진** — 태그로 걸러 보고, 카드에서 바로 ❤️. 상세에서 장별/전체 다운로드
- **🎵 찬양/묵상나눔** — 카드를 누르면 상세가 열리고 유튜브 영상이 재생됩니다
- 글쓰기는 오른쪽 아래 **➕ 버튼**으로 합니다. (지금 보고 있는 서브탭에 맞춰 열립니다)
- 목록은 20개씩 [더보기]로 이어서 불러옵니다.

### 📋 신청

- **🍚 주일식사** — 앞으로 **4주** 중에서 고르고, 성인/어린이 인원을 정합니다.
  **직전 토요일 14시에 자동 마감**됩니다. ([8장](#8-식사-신청--식수-집계--쿠폰))
- **🎉 교회행사** — 관리자가 등록한 행사 안내를 보고 구글 폼으로 신청합니다.
  구글 폼 주소가 없으면 "담당자에게 직접 신청" 안내가 뜹니다.

### 👤 내정보

- 프로필 사진·연락처·주소·생일 수정, 배우자·자녀 정보 입력
- 우리 가정의 **식사 쿠폰 잔액**
- **내 기도제목** 모아보기
- **휴대폰 알림(푸시) 켜기/끄기** ([10장](#10-자동-알림-시각표와-푸시-설정))
- **홈화면 앱 설치 안내** (아이폰 Safari / 안드로이드 Chrome)
- 로그아웃
- **관리 대시보드 입구** (권한이 있는 분에게만)

## 4. 명단에서 빼는 3가지 방법

**가장 헷갈리는 부분입니다.** 목적이 다르니 반드시 구분해서 쓰세요.

### 4.1 한눈에 비교

| | **출석 미적용** | **탈퇴 처리 (기본)** | **탈퇴 처리 (접근 허용)** | **가입 거절** |
|---|:---:|:---:|:---:|:---:|
| 무엇인가 | 라브리 칸의 값 | 등급 `LEFT` | 등급 `LEFT` + 허용 | 등급 `REJECTED` |
| **성도 자격** | 유지 ✅ | 없음 ✗ | 없음 ✗ | 없음 ✗ |
| 출석체크 명단 | **빠짐** ✗ | 빠짐 ✗ | 빠짐 ✗ | 빠짐 ✗ |
| 식수 집계·미응답 알림 | **빠짐** ✗ | 빠짐 ✗ | 빠짐 ✗ | 빠짐 ✗ |
| 주소록 | 나옴 ✅ | 빠짐 ✗ | 빠짐 ✗ | 빠짐 ✗ |
| 생일 달력 | 나옴 ✅ | 빠짐 ✗ | 빠짐 ✗ | 빠짐 ✗ |
| 성도 수 통계 | 포함 ✅ | 빠짐 ✗ | 빠짐 ✗ | 빠짐 ✗ |
| 식권(쿠폰) | 유지 ✅ | — | — | — |
| 본인의 식사 신청 | **가능** ✅ | 불가 ✗ | 불가 (메뉴 사라짐) ✗ | 불가 ✗ |
| 나눔·우리소식 이용 | 가능 ✅ | **불가** ✗ | **가능** ✅ | 불가 ✗ |
| 공지·나눔 알림 | 받음 ✅ | 안 받음 ✗ | — | 안 받음 ✗ |
| 과거 기록 보존 | 그대로 | 그대로 | 그대로 | 그대로 |
| 되돌리기 | 라브리 다시 지정 | 관리자만 복구 | 관리자만 복구 | **본인이 재신청 가능** |

### 4.2 출석 미적용 — "출석체크 명단에서만 빼 주세요"

**성도 자격은 그대로 두고, 출석·식수 집계에서만 빼는 표시입니다.**

**이런 분께 씁니다**
- 배우자로만 이름을 올리는 분
- 일 때문에 장기간 쉬시는 분
- 가끔만 나오시는 분

**설정하는 곳**
```
관리 대시보드 → 📋 성도 → 성도 옆 ✏️ → [소속 라브리] → "출석 미적용" 선택
```
미가입 성도를 추가할 때도 같은 자리에서 고를 수 있습니다.
자녀는 [교회학교 그룹] 칸에서 같은 값을 고릅니다.

**빠지는 것은 딱 두 가지**
1. 출석체크 명단 (리더·선생님의 출석 화면에 이름이 안 뜹니다)
2. 식수 집계와 "아직 식사 신청 안 하셨습니다" 알림

**그대로 남는 것**
- 주소록, 생일 달력, 식권(쿠폰), 공지·나눔 알림
- **오시는 주에는 본인이 직접 식사 신청을 할 수 있습니다.**

**부부 중 한 분만 지정한 경우**
식수 알림은 **사람 단위**라 그분만 조용해지고, 배우자는 계속 알림을 받습니다.
(그 가정은 식사 신청을 해야 하므로 맞습니다.)
관리자 화면의 **미응답 가정** 목록에서는 **가정 전원이 '출석 미적용'일 때만** 가정째로 빠집니다.

**되돌리기**: 다시 나오시면 라브리(1~3)를 골라 주면 원래대로 돌아옵니다.

### 4.3 탈퇴 처리 — 교회를 떠나신 경우

**기록은 지우지 않고 명단에서만 빼는 방식**입니다. (출석·식수 기록 모두 보존)

**처리하는 곳**
```
관리 대시보드 → 📋 성도 → 성도 옆 ✏️ → 맨 아래 [이 성도 탈퇴 처리]
```
> 오조작을 막으려고 목록에는 버튼을 두지 않고 편집 창 안쪽에만 두었습니다.
> 앱에 가입한 분과 미가입 명단 모두 같은 방법으로 처리합니다.

**두 가지 선택지**

| | 체크 안 함 (기본) | ☑️ **탈퇴 처리 후 홈페이지 접근 허용** |
|---|---|---|
| 언제 | 보통의 경우 | 좋게 마무리된 경우 (예: 한국 복귀) |
| 앱 화면 | 홈 외에는 "탈퇴 처리된 계정입니다" 안내만 | 나눔·우리소식·일정을 계속 이용 |
| 신청 메뉴 | 막힘 | **메뉴 자체가 사라짐** |
| 주소록·생일·성도수·출석·식사 | 모두 빠짐 | 모두 빠짐 (동일) |

**복구하기**
```
관리 대시보드 → 📋 성도 → 🚪 탈퇴 처리된 성도 (n명) → 펼치기 → [복구]
```
탈퇴 전 등급이 저장되어 있어 **그대로 되돌아갑니다.**
(옛 데이터라 등급이 없으면 일반 성도로 복구됩니다.)

> ⚠️ 탈퇴한 본인은 **되돌릴 수 없습니다.** 앱에는 "교회 사무실로 연락해 주세요"만 안내됩니다.
> (가입 거절과 다른 점입니다. 거절은 본인이 다시 신청할 수 있습니다.)

**완전 삭제**
탈퇴자 목록에서만 가능하며, 아래 경우에는 **차단**됩니다.
- 출석 기록이 하나라도 있는 분 → 탈퇴 처리만 가능
- 탈퇴 전 마지막 총괄 관리자였던 분

### 4.4 가입 거절

```
관리 대시보드 → 👥 승인 → [거절]
```
계정을 지우지 않고 상태만 바꿉니다. 거절당한 분 화면에는
**[다시 가입 신청하기]** 버튼이 뜨므로, 착오였다면 본인이 다시 신청할 수 있습니다.

> 💡 예전에는 거절하면 프로필을 아예 지웠는데, 로그인 계정은 남아서
> 그분이 앱을 다시 열 때마다 승인 대기 목록에 무한히 다시 올라왔습니다.

## 5. 가입부터 승인까지

### 5.1 전체 흐름

```
① 성도: 구글 또는 카카오로 로그인
      ↓
② 성도: 추가정보 입력 (이름·연락처·주소·생일) → [가입 완료 및 승인 신청]
      ↓   ← 이 버튼을 눌러야만 관리자에게 알림이 갑니다
③ 관리자: 👥 승인 탭에서 라브리·등급·직분·가족 지정 → [승인]
      ↓
④ 성도: 화면이 저절로 바뀌고 🎉 환영 팝업이 뜹니다
```

### 5.2 "승인 대기"는 두 가지 상태입니다 — 꼭 구분하세요

| 상태 | 성도 화면 | 승인 목록에 뜨나요? |
|---|---|---|
| 로그인만 하고 **추가정보 미제출** | "가입 신청이 아직 완료되지 않았습니다" + [가입 신청 이어하기] | **❌ 안 뜹니다** |
| 추가정보 제출 완료 | "가입 승인 대기 중입니다" | ✅ 뜹니다 |

> 성도가 "가입했는데 승인이 안 된다"고 하면 **먼저 이것부터 확인하세요.**
> 추가정보 입력 창을 닫아버린 분은 로그인 상태로 홈에 머물러 있습니다.
> 신청 메뉴를 한 번 눌러 보시라고 하면 [가입 신청 이어하기] 버튼이 나옵니다.

### 5.3 승인 후 자동 반영

- 관리자가 승인을 누르면 **성도 화면이 저절로 바뀝니다.** 앱을 껐다 켤 필요 없습니다.
  (실시간 연결 + 15초마다 확인, 두 겹으로 동작합니다)
- 승인 탭도 **새 가입 신청이 실시간으로 올라옵니다.**
- 승인이 끝나면 성도에게 🎉 환영 팝업이 **딱 한 번** 뜹니다.

## 6. 미가입 성도와 계정 연결(통합)

### 6.1 미가입 성도란

앱을 쓰지 않으시는 분을 **명단에만 올려 두는 기능**입니다.

**들어가는 곳**: 출석체크 명단 ✅ · 식수 쿠폰의 가정 이름 ✅ · 주소록(이름·소속만) ✅
**안 들어가는 곳**: 생일 달력 ❌ · 주소록 세부정보(본인이 관리하는 정보가 아니므로 공란)

**추가하는 법**
```
관리 대시보드 → 📋 성도 → [👤+ 미가입 성도]
→ 이름 · 연락처 · 생일 · 직분 · 라브리 · 가족으로 묶을 성도 · 가족 역할
```
가족으로 묶을 상대에게 아직 가족 번호가 없으면 **자동으로 만들어 양쪽에 붙입니다.**
(그래야 식수 쿠폰의 가정 이름이 두 분 이름으로 나옵니다.)

### 6.2 나중에 그분이 가입하면 — 계정 연결

같은 분이 앱에 가입하면 프로필이 **둘**이 됩니다. 그대로 두면 출석 명단에 이름이 두 번 뜹니다.
➡️ **계정 연결로 하나로 합칩니다.**

**연결하는 법**
```
관리 대시보드 → 📋 성도 → 미가입 성도 카드의 [가입 계정과 연결하기]
→ 연결할 가입 계정 선택 → [연결하기]
```
이름이 같은 미가입 명단과 가입 계정이 함께 있으면
🔗 **"같은 이름으로 가입한 분이 있습니다"** 안내가 자동으로 뜹니다.

**합쳐질 때의 규칙** (어느 쪽 값이 남는지)

| 항목 | 남는 값 |
|---|---|
| 이름 · 연락처 · 주소 · 생일 · 사진 · 이메일 | **가입 계정**(본인이 입력한 값) 우선 |
| 직분 · 라브리 · 가족 | **명단**(관리자가 적어 둔 값) 우선 |
| 등급 | 승인하며 고른 값 |
| 자녀 | 양쪽을 **모두 합침** |
| 출석 · 식수 기록 | 명단에 쌓인 기록이 **그대로 넘어감** |

> ⚠️ **주의 두 가지**
> 1. **이름이 같아도 다른 분일 수 있습니다.** 반드시 **이메일까지 확인**하고 고르세요. 되돌리기 어렵습니다.
> 2. **승인 대기 중인 계정은 고를 수 없습니다.** 먼저 👥 승인 탭에서 승인해야 목록에 나타납니다.
>    (이 경우 화면에 안내가 함께 뜹니다.)

## 7. 출석체크 운영

### 7.1 누가, 무엇을 체크하나

**출석체크 버튼**은 [우리소식] 탭 오른쪽 위에 있습니다. 아래 세 등급에게만 보입니다.

| 등급 | 체크할 수 있는 그룹 |
|---|---|
| **총괄 관리자** | 라브리1 · 라브리2 · 라브리3 · 미정 + 모든 교회학교 그룹 + 방문자 |
| **라브리 리더** | **자기 라브리 하나만** + 방문자 |
| **교회학교 선생님** | 담당 부서(지정 안 하면 모든 부서) + 방문자 |

- 대상 주일은 **가장 최근 지난 주일**로 자동 계산됩니다.
- 교회학교 그룹: 영아부 · 유아·유치부 · 초등부 · 중고등부
- **담당 부서 지정**: 📋 성도 → ✏️ → [담당 자녀 그룹] (복수 선택 가능)
  - 선생님이 하나도 안 고르면 → 모든 부서 담당으로 보고 전체 요약 알림을 받습니다
  - 관리자·리더도 특정 부서를 담당할 수 있습니다 (그 부서 미완료 알림만 받음)
  - **출석체크 자체는 부서 지정과 무관하게 할 수 있습니다.** 지정은 알림 대상을 정할 뿐입니다.

### 7.2 체크 화면에서 할 수 있는 것

- **전원 출석** 단축 버튼
- 결석 사유 선택 (선택사항): `출근/출장` · `여행` · `아파요` · `가족방문`
- 명단에서 빠지는 분: 승인 대기자 · **쿠폰 관리자** · **출석 미적용** · 탈퇴자

### 7.3 방문자 기록

출석체크 창의 **[방문자]** 탭에서 기록합니다. 두 종류가 있습니다.

| | **기명 방문자** | **익명 카운터** |
|---|---|---|
| 무엇 | 이름을 아는 분 | 총원만 세는 숫자 |
| 입력 | 이름 + 분류(성인/중고등부/초등부/유아유치부) + 특이사항(선택) | 성인 / 학생 +1, −1 |
| 쓰임 | 심방·연락으로 이어집니다 | 총원 집계에만 씁니다 |

- 최근에 왔던 분은 **추천 버튼**으로 한 번에 등록됩니다.
- 특이사항(인도자, 비고 등)은 통계 화면에서 눌러 볼 수 있습니다.

### 7.4 출석 통계 보기

```
관리 대시보드 → 📊 출석
```

| 카드 | 내용 | 선생님에게 |
|---|---|---|
| 📊 선택한 주일 출석률 | 라브리별 출석률 + **[전체 합계]** 행 | 가려짐 |
| 출석/결석 명단 | 결석 사유가 표에 그대로 보입니다 | 가려짐 |
| 🧒 교회학교 출석 | 선택한 주일 하루 기준 | 보임 |
| 🏷️ 방문자 현황 | 그 주일의 기명 방문자 + 익명 수 | 보임 |
| 🗓️ 기간 출석률 | 시작~끝 날짜를 정해 합산 (분기·반기·연간) + **CSV 다운로드** | 가려짐 |
| 🏷️ 기간 방문자 | 사람 단위로 합쳐 방문 횟수 표시 (꾸준한 분이 위로) | 보임 |

**연속 결석**: 📋 성도 탭에서 오래 안 나오신 분이 위로 정렬됩니다.
9주까지는 숫자로, 그보다 길면 **`장기`** 로 표시합니다.

## 8. 식사 신청 · 식수 집계 · 쿠폰

### 8.1 성도가 신청하는 법

```
[신청] 탭 → 🍚 주일식사 → 주(앞으로 4주 중) 선택 → 성인/어린이 인원 → 저장
```
- **마감: 직전 토요일 14시 (하노이 시각)** — 남은 시간이 화면에 표시됩니다
- 신청은 **가정 단위**입니다. 부부 중 한 분이 하면 가정 전체 신청이 됩니다
- "식사 안 함"으로 답하는 것도 **응답**입니다. 미응답과 다릅니다

### 8.2 관리자·리더의 식수 집계

```
관리 대시보드 → 🍱 식사
```
- 앞으로 **4주치 예상 식수**가 기본으로 보입니다
- **[📋 식수내용 복사]** — 주방에 넘길 집계를 그대로 복사합니다
- **미응답 가정** 목록 (길어질 수 있어 기본은 접혀 있고, 숫자는 보입니다)
- **[📋 미응답 가정 안내문 복사]** — 단톡방에 붙여넣기용 문구를 만들어 줍니다
- **대신 입력**: 가정 이름(✍️ 표시)을 누르면 대신 신청·수정할 수 있습니다
  → **총괄 관리자 · 리더만** 가능. (선생님은 집계를 볼 수만 있습니다)
  → 앱을 안 쓰시는 가정의 답을 단톡방·전화로 받아 옮겨 담을 때 씁니다

### 8.3 쿠폰(식권) 관리

```
관리 대시보드 → 🎟️ 쿠폰   (총괄 관리자 · 쿠폰 관리자)
```
- 가구별 **발급 `+1`** / **차감 `−1`** / **10장 일괄 발급**
- 💳 **식사쿠폰 구매** — QR코드/계좌 안내 화면. 입금 확인 후 관리자가 발급합니다
- 성도는 [내정보]에서 **우리 가정 잔액**을 확인합니다

## 9. 주보 작성과 인쇄

```
관리 대시보드 → 📖 주보   (총괄 관리자 전용)
```

### 9.1 작성 흐름

```
① 주일 날짜 선택 (앞으로 2주 + 지난 주보 목록)
② [지난 주보 불러오기] — 예배순서·섬김표·헌금계좌는 거의 안 바뀝니다
③ 4쪽 구조 그대로 섹션별 입력
④ [미리보기] — 실제 지면 그대로 보며 넘침을 눈으로 확인
⑤ [임시저장] 또는 [발행]
```

### 9.2 알아두면 좋은 것

- **[절 나누기]** — 성경 본문을 통째로 붙여넣으면 절 단위로 잘라 줍니다
- **대표기도자**는 이름을 치지 않고 **가입 성도 중에서 고릅니다.**
  계정과 연결되어 나중에 그분에게만 알림을 보낼 수 있고, 예배 순서의 '기도' 줄에 자동 반영됩니다
- **발행/임시저장** — 발행하면 성도 홈 화면에 올라가고 알림이 나갑니다. 발행을 거둘 수도 있습니다
- **지난 주일 + 발행 완료** 주보는 **읽기 전용**입니다 (참고용 열람). 수정 버튼이 숨겨집니다
- 새로 만들 수 있는 미래 주일은 **이번 주 포함 2주치**까지입니다

### 9.3 인쇄

```
주보 탭의 🖨️ 인쇄 버튼  또는  /bulletin/print?date=YYYY-MM-DD
```
`date`를 빼면 가장 최근 주보가 나옵니다. **A4 가로 2장** → 반으로 접으면 A5 4쪽입니다.
앞면 `[4|1]` · 뒷면 `[2|3]`

**인쇄 설정 (중요)**

| 항목 | 값 |
|---|---|
| 용지 | A4 |
| 방향 | **가로** |
| 배율 | 100% |
| 여백 | 없음 |
| 배경 그래픽 | **켜기** |
| 양면 | **긴 쪽으로 넘기기 (long edge)** |

## 10. 자동 알림 시각표와 푸시 설정

### 10.1 서버가 알아서 보내는 알림 (베트남 시각 기준)

| 알림 | 보내는 때 | 푸시 | 받는 사람 / 내용 |
|---|---|:---:|---|
| 🍚 **식사 미응답** | 1차 **금 20시** · 2차 **토 12시** | ✅ | 다가오는 주일 식사를 아직 신청 안 한 가정 (2차는 마감 2시간 전) |
| 📖 **새 주보 알림** | 금·토 **저녁 8시** | ✅ | 전 성도 (주보 1건당 딱 한 번) |
| 🎂 **생일 축하** | 매일 **아침 8시** | ✅ | 생일자 본인 + 우리소식에 교회 명의 축하글 |
| 📋 **출석 리마인더** | 1차 **일 20시** · 2차 **월 12시** · 3차 **월 20시** | ✅ | 출석이 아직 입력 안 된 라브리의 **리더** |
| 🔔 **안읽은 알림 요약** | **오전 11시** · **오후 9시** | ✅ | 확인 안 한 알림이 있는 성도 (모두 읽었으면 발송 안 함) |
| 📝 **정보 보완 요청** | 매주 **금 20시** | ✗ | 주소 보완 대상자 · 자녀 생일 미입력 성도 (앱 안 알림만) |
| 🧹 **오래된 알림 정리** | 매일 **새벽 4시** | ✗ | 60일 지난 알림 자동 삭제 |

> 이 목록은 관리 대시보드 → 🔔 **알림** 탭에서 **보기 전용**으로 확인할 수 있습니다.

### 10.2 관리자가 직접 보내는 알림

```
관리 대시보드 → 🔔 알림 → 제목 · 내용 · 받는 사람 선택 → 보내기
```
- **빠른 선택 그룹**: 전체 / 라브리별 / 라브리 리더 / 선생님 / 관리자
- 그룹 버튼을 눌러도 실제 발송은 **항상 체크된 개인 목록** 기준이라, 겹치는 사람도 **한 번만** 받습니다
- 보내는 이를 **"더브릿지 교회"** 명의로 할지, 내 이름으로 할지 고를 수 있습니다
- ⚠️ **알림은 되돌릴 수 없습니다.** 보내기 전 확인 창이 한 번 뜹니다

### 10.3 성도의 푸시 설정 안내

```
[내정보] → 휴대폰 알림 스위치
```
- 스위치를 켜면 브라우저가 알림 권한을 묻습니다. **허용**해야 켜집니다
- 한 번 **차단**하면 스위치로는 못 켭니다 → 휴대폰 설정에서 알림 차단을 풀어야 합니다
- **아이폰은 홈화면에 앱을 추가해야 푸시가 옵니다.** [내정보] 아래쪽 설치 안내를 따라 주세요

### 10.4 앱(PWA) 설치 안내

| 기기 | 방법 |
|---|---|
| 아이폰 (Safari) | 공유 버튼 → "홈 화면에 추가" |
| 안드로이드 (Chrome) | [내정보]의 설치 버튼 한 번 (지원 안 되면 메뉴 → "홈 화면에 추가") |

## 11. 분석 페이지 (/analytics)

**총괄 관리자 전용**입니다. 주소창에 `/analytics`를 직접 입력해 들어갑니다.
(메뉴에는 없고, 검색엔진에도 노출되지 않습니다.)

로그인 방법은 **관리자 이메일/비밀번호** 또는 **구글 계정** 두 가지입니다.
관리자가 아닌 계정으로 들어가면 "접근 권한 제한" 화면이 뜹니다.

**볼 수 있는 것**

- 📊 핵심 요약 카드 6종
- ⏰ 시간대별 접속 피크 (0~23시)
- ⛪ 주일 예배 출석 & 식사 통계 추이
- 📱 기기 및 실행 환경 점유율 (아이폰/안드로이드, 홈화면 앱 사용 여부 등)
- 💗 **목회 돌봄 관심 성도** — 앱에는 들어오는데 **2주 이상 결석** 중인 분
- 👤 개인별 성도 목록 / 👨‍👩‍👧 가족 단위 통합 보기 (전환 가능)
- 📋 미가입 성도 명단

## 12. 자주 겪는 상황과 해결

### 가입 · 승인

**Q. 성도가 "가입했는데 승인 목록에 없다"고 합니다**
A. **[가입 완료 및 승인 신청] 버튼을 안 누른 상태**입니다. 추가정보 입력 창을 닫으면 이렇게 됩니다.
그분에게 [신청] 메뉴를 한 번 눌러 보시라고 하면 **[가입 신청 이어하기]** 버튼이 나옵니다.

**Q. 승인했는데 성도 화면이 그대로랍니다**
A. 보통은 **저절로 바뀝니다.** 안 바뀌면 그분 화면의 [승인 상태 새로고침]을 누르시라고 하세요.
그래도 안 되면 저장이 실패했을 수 있으니 승인 탭에 아직 남아 있는지 확인하세요.

**Q. 승인 탭에 계속 같은 분이 다시 올라옵니다**
A. 거절은 계정을 지우지 않고 상태만 바꾸므로 이런 일은 없어야 합니다.
같은 분이 **다시 신청**했을 수 있습니다 (거절당한 분은 본인이 재신청할 수 있습니다).

**Q. "성도 명단을 불러오지 못했습니다" 배너가 떴습니다**
A. 네트워크 문제입니다. **목록이 비어 보여도 실제로 비어 있는 게 아닙니다.**
[다시 시도]를 누르세요. 이 배너가 뜬 상태의 숫자는 믿지 마세요.

### 명단 · 출석

**Q. 같은 분이 출석 명단에 두 번 뜹니다**
A. 미가입 명단과 가입 계정이 따로 있는 경우입니다.
📋 성도 탭의 🔗 **"같은 이름으로 가입한 분이 있습니다"** 안내에서 **연결**해 주세요. ([6.2](#62-나중에-그분이-가입하면--계정-연결))

**Q. 가끔만 나오시는 분께 매주 식사 알림이 갑니다**
A. 라브리를 **'출석 미적용'** 으로 바꿔 주세요. 출석 명단과 식수 알림에서만 빠지고,
주소록·생일·식권은 그대로입니다. ([4.2](#42-출석-미적용--출석체크-명단에서만-빼-주세요))

**Q. 교회를 떠나신 분을 어떻게 처리하나요**
A. **탈퇴 처리**입니다. 기록은 그대로 남고 명단에서만 빠집니다.
좋게 마무리된 경우라면 **[홈페이지 접근 허용]** 을 체크해 나눔은 계속 쓰시게 할 수 있습니다. ([4.3](#43-탈퇴-처리--교회를-떠나신-경우))

**Q. 자녀가 주소록·출석 어디에도 안 나옵니다**
A. **교회학교 그룹이 지정 안 된 자녀**입니다. 📋 성도 탭에 숫자로 표시되니
✏️ → 자녀의 그룹을 골라 주세요.

**Q. 쿠폰 관리자가 성도 명단에 안 보입니다**
A. 정상입니다. `COUPON`은 업무 계정이라 주소록·생일·출석·식수·성도 수에서 모두 빠집니다.
성도이기도 한 분이라면 등급을 **일반 성도**로 바꾸세요.

### 식사 · 주보

**Q. 식사 신청이 마감됐는데 추가해야 합니다**
A. 총괄 관리자·리더가 🍱 식사 탭에서 가정 이름(✍️)을 눌러 **대신 입력**할 수 있습니다.

**Q. 주보를 고치려는데 입력칸이 잠겨 있습니다**
A. **지난 주일 + 발행 완료** 주보는 읽기 전용입니다. 이번 주 이후 날짜를 고르세요.

**Q. 인쇄하면 잘리거나 배경이 안 나옵니다**
A. 인쇄 설정을 확인하세요. **A4 / 가로 / 100% / 여백 없음 / 배경 그래픽 켜기** ([9.3](#93-인쇄))

### 알림

**Q. 푸시 알림이 안 옵니다**
A. 순서대로 확인하세요.
1. [내정보]의 휴대폰 알림 스위치가 켜져 있나요?
2. 아이폰이면 **홈화면에 앱을 추가**했나요? (Safari에서 그냥 열면 푸시가 안 옵니다)
3. 휴대폰 설정에서 알림이 **차단**돼 있지 않나요? (한 번 차단하면 앱 스위치로는 못 켭니다)

**Q. 출석 리마인더가 엉뚱한 선생님께 갑니다**
A. 📋 성도 → ✏️ → **[담당 자녀 그룹]** 을 지정해 주세요.
지정하지 않은 선생님은 "모든 부서 담당"으로 보고 전체 요약 알림을 받습니다.
